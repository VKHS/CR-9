# Data and code availability statement

Each item of the paper's data and code availability statement and where the repository provides it. `make statement-check` checks every item; `make statement-fulfilled` also downloads the complete artifacts and runs the reconstruction.

| Statement item | Provided by |
|---|---|
| complete experiment code | `cross_morse/`, `cm_experiments/`, `cm_campaigns/` and `scripts/`; [release/experiment_code.json](release/experiment_code.json) maps every experiment to its code |
| configurations | [configs/](configs/) and the experiment configurations |
| source data | the source data of every display, which [the publication step](docs/PUBLICATION.md) writes to `paper/source_data/`; dataset sources in [data/sources.json](data/sources.json) |
| split and seed manifests | [manifests/registered/](manifests/registered/); [the publication step](docs/PUBLICATION.md) writes the executed role memberships and seeds to `manifests/published/` |
| environment specification | [environment/](environment/) and [Dockerfile](Dockerfile); [the publication step](docs/PUBLICATION.md) adds the observed environment of each run (`environment/observed/`) |
| checkpoints | the run archives that [the publication step](docs/PUBLICATION.md) uploads to the release `paper-artifacts`, recorded in [release/paper_artifacts.json](release/paper_artifacts.json) |
| predictions | the same run archives |
| propensity-logged trajectories | the same run archives |
| statistical outputs | the measurement-record sets and campaigns that [the publication step](docs/PUBLICATION.md) uploads to the same release, with the run and record indexes [runs/index.json](runs/index.json) and [records/index.json](records/index.json) |
| figure/table generators | [paper/build/displays/](paper/build/displays/), one generator for each of the 90 numbered displays |
| one-command reconstruction of every reported table and figure | `make paper` ([Reconstruction](docs/RECONSTRUCTION.md)) |
| follows established reproducibility guidance | [REPRODUCIBILITY.md](REPRODUCIBILITY.md) |

Generated by `scripts/statement_check.py --write`; `make statement-check` verifies it is current.
