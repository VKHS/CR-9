# Data and code availability

The repository provides the experiment code, configurations, environment specification and the generators of all 90 numbered tables and figures. [The publication step](docs/PUBLICATION.md) packs the measured outputs of the reported runs (checkpoints, predictions, propensity-logged trajectories and statistical outputs) into the release `paper-artifacts` and records each artifact in [release/paper_artifacts.json](release/paper_artifacts.json). `make paper` downloads and verifies them, rebuilds every numbered table and figure with its source data and compares each computed value with the value printed in the paper ([Reconstruction](docs/RECONSTRUCTION.md)). `bash run_cross_morse.sh reproduce` regenerates the runs on a Slurm GPU cluster ([HPC guide](docs/HPC.md)).

[Statement compliance](STATEMENT_COMPLIANCE.md) maps each item of the availability statement to where it is provided.

Generated by `scripts/availability.py`; `make availability-check` verifies it is current.
