Data and code availability. The CROSS-MORSE implementation, seven dataset adapters and their configurations, split and seed design manifests, environment specifications, statistical analysis code, supported table and figure builders, and manuscript reference values are available at https://github.com/VKHS/CR-9. The repository also provides a Slurm lifecycle launcher, E3–E6 campaign tools, a pinned-upstream baseline driver, timing/accounting tools and measurement-record exporters. Official datasets are obtained from their providers through the adapters. The launcher (bash run_cross_morse.sh reproduce) executes the registered dataset lifecycles, including Roman-empire's ten official splits. Each new run records its source/configuration identity, actual data-role membership, seeds, environment, checkpoints, predictions, exploration propensities and decision records; its report compares supported run-derived quantities with the paper. Auxiliary campaigns follow their separate documented protocols. make reconstruct assembles the supported numerical outputs and reports the input and build scope of every numbered display. The artifact catalog (docs/ARTIFACT_CATALOG.md) distinguishes bundled files, external-provider data, generated outputs and registered experiment archives; paper/PAPER_SUPPORT.md records display-specific coverage. Two complete synthetic example runs support software verification without benchmark data. This code release packages those examples; it does not package the original benchmark run archives. Original experiments and subsequent reproductions retain separate provenance and manuscript-relationship declarations.
